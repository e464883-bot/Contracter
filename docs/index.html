              OPERACIÓN LOCALCómo usar este chasis+
              1. Explora la demostración. El JSON de data/sample_case.json alimenta esta vista; todos sus resultados y costos son simulados.
              2. Abre otro expediente. Usa «Abrir expediente JSON» para leer un archivo desde tu equipo. No se sube a un servidor. Si abriste el HTML directamente, este selector también funciona sin servidor HTTP.
              3. Prepara los enchufes. Copia .env.example a un entorno privado del servidor y revisa los workflows de n8n. Mantén el modo mock durante las pruebas. Este frontend no lee archivos .env.
              4. Valida antes de publicar. El script scripts/validate_case_json.py comprueba estructura y controles. La vista de navegador no reemplaza esa validación ni la aprobación verificable del abogado responsable.
              5. Publica sólo con autorización. Los eventos push y pull_request ejecutan validaciones. El despliegue requiere iniciar manualmente workflow_dispatch con publish=true, casos live con aprobación autenticada por HMAC y el entorno protegido legal-approval. Esta entrega no activa ese proceso.
              La publicación en Pages sirve únicamente para expedientes autorizados y anonimizados. Un archivo importado se presenta como contenido local sin verificación de identidad, firma ni vigencia legal. No se puede aprobar un contrato desde este panel. La web es estática: no requiere npm, una compilación ni una carpeta dist.
